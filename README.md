# Weekend Data Challenge #05: Tech Layoffs Analysis

This project cleans and analyzes the Kaggle Tech Layoffs dataset using Python and Pandas. 

## 🚀 Key Steps Covered:
- Data cleaning (handling whitespace, missing values, and date parsing).
- Aggregating total layoffs by industry and month.
- Visualizing top impacted industries and timeline trends using Matplotlib & Seaborn.
- Addressing the bonus question to contrast total counts versus percentage impacts.

## 🛠️ Tools Used:
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Google Colab
